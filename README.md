### 1. [MiniSocial (`minisocial/`)](./minisocial/)
A lightweight social networking web application featuring user profiles, feeds, and post interactions.
- **Tech Stack:** Django, Python, HTML/CSS, JavaScript, SQLite.

### 2. [Simple E-Commerce Store (`ecommerce_store/`)](./ecommerce_store/)
A full-stack, responsive online shopping store (ShopZone) with catalog browsing, product details, session-based shopping cart, and order processing.
- **Features:**
  - Product catalog with live search, category filtering, and sorting
  - Product details page with stock management and quantity picker
  - Shopping cart with AJAX updates and real-time total recalculations
  - Order checkout with customer details form and multiple payment methods (COD, Card Demo, UPI Demo)
  - Order confirmation with invoice and printable receipt
  - User Authentication (Login / Registration) & "My Orders" customer dashboard
  - Pre-configured Django Admin Portal (`/admin/`) for product and order management
- **Tech Stack:** Django, Python, HTML5, CSS3, JavaScript (Vanilla), SQLite.
- **Documentation & Setup:** See [ecommerce_store/README.md](./ecommerce_store/README.md).
